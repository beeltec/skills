# Applicability

One short-lived branch per feature or issue, integrated into main after review.

# Verified claims

- The feature branch workflow treats main as official project history.
- Use a separate branch for each feature or issue.
- Create feature branches from the latest main state.
- Merge approved, conflict-free feature branches into main.
