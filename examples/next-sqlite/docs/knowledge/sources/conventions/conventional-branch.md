# Applicability

One purpose-driven local branch for every non-epic implementation ticket.

# Verified claims

- A prefixed branch uses the form type/description.
- Purpose prefixes include feature or feat, bugfix or fix, hotfix, release, and chore.
- Descriptions use lowercase alphanumerics with single hyphens or dots as separators.
- A ticket number may be included to support traceability.
