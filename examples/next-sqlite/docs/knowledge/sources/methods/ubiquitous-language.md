# Verified claims

- A ubiquitous language is shared by the people who understand the domain and the people who build the software.
- Use the same agreed language in conversation, writing, diagrams, and code when they describe the same concept.
- Treat a changed term meaning as a changed project model that needs deliberate agreement.
