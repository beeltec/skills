# Project backlog

This tracked backlog owns desired changes and execution state. The [project wiki](../wiki/index.md) remains authoritative for accepted current state on the primary branch.

## Work areas

- [Maintenance](maintenance.md) - Required hierarchy, lifecycle, readiness, relationship, ranking, claim, and archive rules.
- [Epics](epics/) - Active outcome-centered Epics and their peer Stories, Tasks, and Bugs.
- [Standalone work](standalone/) - Active executable work that has no Epic parent.
- [Archive](archive/) - Completed or cancelled Epics and standalone work.
- [Templates](templates/) - Canonical records for each backlog item type.

## Global executable-work rank

No executable work is ranked. Add every active `WORK-NNN` exactly once as an ordered Markdown link; position 1 is the next work item.
