# Engineering technologies

Add one canonical page per language, framework, runtime, library, or major tool. Each page follows the [guidance page template](/engineering/guidance-template.md) and records the installed version with its establishing path, adopted rules binding on new code, project conventions and deviations, known non-compliant areas, and labeled web sources. Create or refresh pages via `$develop guidance ...`, which can also publish durable conclusions promoted from proposal research after acceptance.
